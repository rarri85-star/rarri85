# Zettelkasten/00. Inbox/

## 목적과 역할
머릿속에 떠오른 생각, 링크, 인용구를 마찰 없이 빠르게 캡처하는 임시 보관함입니다.
완성도보다 속도가 우선입니다. 여기서 오래 머무는 노트는 없어야 합니다.

## 어떤 노트가 들어가는가
- 즉각적인 아이디어·질문·영감
- 나중에 읽을 링크나 자료
- 아직 분류되지 않은 단상
- 다른 앱(모바일 등)에서 이동해 온 빠른 메모

## 작업 방식과 규칙
- 매일 또는 주 1~2회 Inbox를 처리(Triage)
- 처리 시 각 메모를 다음 중 하나로 이동:
  - `10. Literature/` — 외부 자료 기반 메모
  - `20. Permanent/` — 자신의 아이디어로 발전된 메모
  - `Resources/` / `Projects/` / `Areas/` — 해당 영역의 자료
  - 삭제 — 더 이상 가치 없는 메모
- Inbox가 비어있는 상태를 목표로 유지 (Zero Inbox)
- 제목 앞에 날짜 prefix 불필요 (Obsidian 생성 시각으로 충분)
