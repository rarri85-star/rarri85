# Resources/

## 목적과 역할
관심 있는 주제의 참고 자료를 모아두는 폴더입니다.
Projects나 Areas에 직접 속하지 않지만 언젠가 유용할 외부 지식을 보관합니다.

## 어떤 노트가 들어가는가
- 책 / 논문 / 아티클 요약
- 강의 · 영상 · 팟캐스트 정리
- 도구 사용법 및 참고 가이드
- 주제별 큐레이션 (기술, 철학, 디자인 등)

주제별 하위 폴더로 구분합니다 (예: `Resources/개발/`, `Resources/독서/`).

## 작업 방식과 규칙
- 자료 자체의 요약·정리이며 자신의 생각은 최소화 (생각은 `Zettelkasten/`으로)
- 출처(URL, 저자, 출판연도)를 frontmatter에 반드시 기재
- Literature Note로 발전시킬 자료는 `Zettelkasten/10. Literature/`에도 복사·연결
- 관심이 식은 자료는 `Archive/`로 이동
