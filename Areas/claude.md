# Areas/

## 목적과 역할
마감일 없이 지속적으로 유지·관리해야 하는 삶의 영역을 담는 폴더입니다.
"프로젝트"가 아닌 "역할"과 "책임"의 단위입니다.

## 어떤 노트가 들어가는가
- 건강 / 운동 / 식단 관리
- 재정 / 지출 / 투자 현황
- 커리어 / 역량 개발 / 학습 방향
- 관계 / 네트워크 관리
- 취미 / 사이드 프로젝트 개요

각 영역은 `Areas/영역명/` 하위 폴더로 분리합니다.

## 작업 방식과 규칙
- Areas 노트는 완료되지 않음 — 지속적으로 업데이트
- 특정 목표나 산출물이 생기면 해당 항목을 `Projects/`로 분리
- 더 이상 관리하지 않는 영역은 `Archive/`로 이동
- 주간 리뷰 시 각 영역의 현황 점검 (Templates/의 주간 리뷰 템플릿 활용)
