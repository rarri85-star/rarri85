# Projects/

## 목적과 역할
마감일이 있고 명확한 완료 조건이 있는 프로젝트를 관리하는 폴더입니다.
언젠가 끝나는 작업 단위만 여기에 둡니다.

## 어떤 노트가 들어가는가
- 프로젝트 계획서 및 목표 정의
- 프로젝트별 미팅 노트 / 회의록
- 진행 상황 추적 (체크리스트, 타임라인)
- 결과물 초안 및 작업 파일 참조

각 프로젝트는 `Projects/프로젝트명/` 하위 폴더로 분리합니다.

## 작업 방식과 규칙
- 프로젝트 생성 시 `Templates/`의 프로젝트 템플릿 사용
- 프로젝트 노트 상단에 마감일(due), 상태(status), 관련 Area 링크를 frontmatter로 명시
- 완료된 프로젝트는 `Archive/`로 통째로 이동 (삭제 금지)
- 진행 중인 프로젝트 수는 가능한 3~5개 이내로 유지
