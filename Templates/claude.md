# Templates/

## 목적과 역할
반복적으로 사용하는 노트 구조를 템플릿으로 저장해두는 폴더입니다.
Obsidian의 Templates 코어 플러그인과 연동됩니다.

## 어떤 노트가 들어가는가
- 프로젝트 킥오프 템플릿
- Literature Note 템플릿
- Permanent Note 템플릿
- 일간 노트 (Daily Note) 템플릿
- 주간 리뷰 템플릿
- 미팅 노트 템플릿

## 작업 방식과 규칙
- 이 폴더의 파일은 템플릿 전용 — 직접 내용을 채우지 않음
- Obsidian 설정 > Templates > 템플릿 폴더 위치를 `Templates`로 지정
- 템플릿 변수: `{{title}}`, `{{date}}`, `{{time}}` 등 Obsidian 기본 변수 사용 가능
- 새 템플릿 필요 시 기존 템플릿을 복사하여 수정
- 템플릿 파일명은 `tpl-` prefix 사용 권장 (예: `tpl-project`, `tpl-literature`)
