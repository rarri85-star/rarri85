# Archive/

## 목적과 역할
완료되었거나 더 이상 활성화하지 않는 모든 항목을 보관하는 폴더입니다.
삭제 대신 아카이브하여 과거 맥락을 보존합니다.

## 어떤 노트가 들어가는가
- 완료된 Projects 전체 폴더
- 더 이상 유지하지 않는 Areas 폴더
- 오래된 Resources 자료
- 중단된 아이디어나 초안

## 작업 방식과 규칙
- 이동만 허용 — Archive 내에서 새 노트를 직접 생성하지 않음
- 폴더 구조는 원본 위치를 반영하여 보존 (`Archive/Projects/프로젝트명/`)
- 아카이브된 항목은 수정하지 않음 (필요 시 Projects/Areas로 복원 후 수정)
- 검색으로 충분히 접근 가능하므로 정기적 정리 불필요
